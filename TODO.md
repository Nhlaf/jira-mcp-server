# Team Demo TODO

## Goal

Each team uses **both systems** to answer its assigned questions. Show the
systems working in a live demo, and explain the answer using what you observed.
Do not answer from theory alone.

## Team A

- [ ] **Architecture:** How does each system connect the AI agent to Jira, and
  where does the Jira integration live?
- [ ] **Code coupling:** How tightly is the Jira functionality coupled to the
  agent framework?
- [ ] Demo one Jira question in both systems and show how the request reaches
  Jira.

## Team B

- [ ] **Reusability:** Can the same Jira capabilities be reused by another AI
  application without duplicating or rewriting code?
- [ ] **Integration effort:** How much code/configuration is required to add a
  new Jira capability or connect another external system?
- [ ] Demo how each system would be reused by another application or extended
  with one new Jira capability.

## Team C

- [ ] **Tool discovery:** How does the agent discover what Jira tools are
  available in each system?
- [ ] **Security & governance:** How are authentication, authorization,
  permissions, auditing, and tool access handled in each system?
- [ ] Demo how each system finds its Jira tools. Show the relevant
  authentication and access settings without displaying secret values.

## Team D

- [ ] **Maintainability:** If the Jira API or business rules change, which
  parts of the system need to be modified?
- [ ] **Scalability:** What happens when you have **10 different AI
  agents/applications** that all need access to the same Jira capabilities?
- [ ] Demo or walk through how each system would handle one Jira change and
  how 10 applications would connect to Jira.

## What each team should present

- [ ] Show both systems answering or demonstrating the assigned questions.
- [ ] Explain what you did and what you observed.
- [ ] Compare the systems using examples from the demo.
- [ ] Say when you could not verify an answer; do not guess.
